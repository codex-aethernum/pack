# Планы

Отложенное больше не живёт здесь — оно заведено как **issue** в организации
[codex-aethernum](https://github.com/codex-aethernum), чтобы собираться в
проект релизов.

| Задача | Где |
|---|---|
| Переезд на Enhanced Celestials 2 | [pack#1](https://github.com/codex-aethernum/pack/issues/1) |
| Sable и mekanicalcreate знают не ту версию Copycats+ | [pack#2](https://github.com/codex-aethernum/pack/issues/2) |
| JEI-плагин Create: More Catalysts падает | [pack#3](https://github.com/codex-aethernum/pack/issues/3) |
| Развязать две копии скриптов проверок | [pack#4](https://github.com/codex-aethernum/pack/issues/4) |
| Баланс и прогрессия: наполнить `00_expert_gating.js` | [pack#5](https://github.com/codex-aethernum/pack/issues/5) |
| Обновить книгу под новый состав и установить | [book#2](https://github.com/codex-aethernum/book/issues/2) |
| Починка тега `chest_armor` в Cold Sweat | [fork-coldsweat#1](https://github.com/codex-aethernum/fork-coldsweat/issues/1) |

Порядок работ проставлен ссылками внутри самих issue. Ключевая цепочка:

**баланс и прогрессия → релиз сборки → дельта состава → обновление книги → установка книги**

Метки одинаковые во всех репозиториях: `совместимость`, `прогрессия`,
`инфраструктура`, `решение` (последняя — там, где сначала надо выбрать, а
потом делать).

Новое отложенное заводи сразу issue, а не сюда.
